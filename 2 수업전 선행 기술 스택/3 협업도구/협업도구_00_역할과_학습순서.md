
> 대상: AI 네이티브 데이터 플랫폼 엔지니어 과정을 처음 시작하는 주니어  
> 목적: 수업에서 사용하는 협업 도구의 역할을 구분하고, 어떤 도구를 언제 사용해야 하는지 이해한다.

---

## 1. 왜 협업 도구를 먼저 이해해야 하는가?

AI 네이티브 데이터 플랫폼 수업은 단순히 코드를 작성하는 과정이 아니다.

수업 중에는 다음 산출물이 계속 만들어진다.
```text
개인 수업 노트
개념 정리
실습 기록
오류 해결 기록
팀 회의록
요구사항 정리
작업 카드
GitHub 커밋
Pull Request
README
데이터 흐름도
대시보드 화면 설계
최종 발표 자료
```

이 산출물을 아무 곳에나 섞어두면 나중에 찾기 어렵다.  
그래서 도구별 역할을 먼저 나누어야 한다.

---

## 2. 협업 도구 전체 역할 요약

| 도구 | 핵심 역할 | 수업에서의 사용 목적 |
|---|---|---|
| Obsidian | 개인 학습 노트 | 개념 정리, 수업 복습, 오류 해결 기록 |
| Notion | 팀 협업 문서 | 회의록, 역할 분담, 팀 산출물, 제출물 관리 |
| Jira / GitHub Issues | 작업 관리 | 기능 단위 작업 카드, 담당자, 진행 상태 관리 |
| Figma / FigJam | 화면 설계와 아이디어 정리 | 대시보드 화면 구조, 발표용 시각화, 팀 아이디어 보드 |
| Discord | 커뮤니케이션 | 공지, 질문, 코드 공유, 팀별 소통 |
| GitHub | 코드와 산출물 관리 | 브랜치, 커밋, PR, README, 실습 결과물 저장 |

## 3. 가장 중요한 구분

수업에서는 아래 기준으로 기억하면 된다.
```text
Obsidian = 개인 정리
Notion = 팀 문서
Jira / GitHub Issues = 작업 관리
Figma / FigJam = 화면과 아이디어 시각화
Discord = 대화와 공지
GitHub = 코드와 최종 산출물
```

## 5. 수업 초반에 먼저 배울 도구

수업 초반에는 모든 도구를 깊게 배우지 않는다.  
처음에는 다음 도구만 먼저 익히면 충분하다.
```text
1. Obsidian
2. GitHub
3. Markdown
4. Discord
```

이유는 다음과 같다.

| 도구 | 초반에 필요한 이유 |
|---|---|
| Obsidian | 개인 수업 노트와 개념 정리에 필요 |
| GitHub | 실습 산출물 저장과 제출에 필요 |
| Markdown | README와 수업 문서 작성에 필요 |
| Discord | 공지, 질문, 코드 공유에 필요 |

---

## 6. 프로젝트가 시작되면 추가로 배울 도구

팀 프로젝트가 시작되면 다음 도구를 추가로 사용한다.
```text
1. Notion
2. Jira 또는 GitHub Issues
3. Figma 또는 FigJam
```

이유는 다음과 같다.

| 도구 | 프로젝트에서 필요한 이유 |
|---|---|
| Notion | 팀 회의록, 역할 분담, 제출물 관리 |
| Jira / GitHub Issues | 작업 카드, 담당자, 진행 상태 관리 |
| Figma / FigJam | 화면 구조, 아이디어 정리, 발표용 시각화 |

---

## 7. 도구를 너무 많이 쓰면 생기는 문제

도구가 많아지면 오히려 혼란이 생긴다.
```text
자료가 어디 있는지 모른다.
회의록과 코드가 섞인다.
작업 담당자가 불명확하다.
완료된 작업과 진행 중인 작업을 구분하기 어렵다.
최종 제출물이 어디에 있는지 모른다.
```

그래서 도구를 많이 쓰는 것보다 **역할을 나누어 쓰는 것**이 중요하다.

---

## 8. 수업 권장 운영 방식

개인 단위
```text
Obsidian에 수업 노트 작성
Markdown으로 개념 정리
오류 해결 기록 남기기
GitHub에 개인 실습 결과 push
```

팀 단위
```text
Notion에 회의록 작성
Jira 또는 GitHub Issues에 작업 카드 등록
GitHub 브랜치에서 기능 개발
Pull Request로 리뷰와 병합
Discord에서 질문과 공지 공유
Figma/FigJam으로 화면과 발표 구조 정리
```

## 9. 수업에서 도구별 최종 산출물

| 도구 | 최종 산출물 |
|---|---|
| Obsidian | 개인 학습 노트, 개념 정리, 오류 해결 기록 |
| Notion | 팀 회의록, 역할 분담표, 제출물 링크 모음 |
| Jira / GitHub Issues | Epic, Story, Task, Bug, 진행 상태 |
| Figma / FigJam | 대시보드 화면 구조, 발표용 시스템 구조 |
| Discord | 공지, 질문 기록, 코드 공유 기록 |
| GitHub | 코드, README, docs, sample_events, PR 기록 |
