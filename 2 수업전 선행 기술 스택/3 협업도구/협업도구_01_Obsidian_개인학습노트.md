
> 역할: 개인 수업 정리와 개념 연결  
> 사용 시점: 수업 시작부터 끝까지  
> 핵심 목적: 내가 이해한 내용을 내 언어로 정리한다.

---

## 1. Obsidian은 무엇인가?
Obsidian은 Markdown 파일을 기반으로 개인 지식 노트를 만드는 도구이다.

수업에서는 Obsidian을 다음 용도로 사용한다.
```text
개인 수업 노트
개념 정리
실습 중 오류 해결 기록
질문 정리
복습 자료
단계별 학습 회고
```

Obsidian은 팀 공식 문서보다 **개인 학습 정리**에 더 적합하다.

---

## 2. Obsidian의 역할
```text
Obsidian = 개인 학습 저장소
```

주니어는 수업 중 다음 내용을 Obsidian에 정리한다.
```text
오늘 배운 개념
이해가 안 된 용어
실습 중 발생한 오류
해결한 명령어
중요한 코드 흐름
내가 다시 봐야 할 질문
```

## 5. Obsidian 내부 링크

문서끼리 연결할 때는 다음 문법을 사용한다.
```markdown
[[문서명]]
```

예시:
```markdown
[[Raw Staging Mart]]
[[Data Contract]]
[[Git 기본 명령어]]
```

특정 제목으로 이동하려면 다음처럼 작성한다.
```markdown
[[문서명#제목]]
```

예시:
```markdown
[[Git 기본 명령어#git status]]
```

## 7. Obsidian과 Notion의 차이

| 구분 | Obsidian | Notion |
|---|---|---|
| 주 용도 | 개인 학습 정리 | 팀 협업 문서 |
| 저장 방식 | 로컬 Markdown 파일 | 온라인 문서 |
| 적합한 내용 | 개념, 오류, 복습 | 회의록, 역할 분담, 제출물 |
| 사용 기준 | 나를 위한 정리 | 팀이 함께 보는 정리 |

---

## 8. 수업에서의 사용 원칙
```text
개인적으로 이해한 내용은 Obsidian에 정리한다.
팀원 모두가 봐야 하는 내용은 Notion에 정리한다.
코드와 최종 산출물은 GitHub에 저장한다.
```
