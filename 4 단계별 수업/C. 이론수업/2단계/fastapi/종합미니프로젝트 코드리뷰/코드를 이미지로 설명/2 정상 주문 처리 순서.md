## ① Sample JSON 준비

```
sample_events/order_created.sample.json
```

이 파일은 정상 주문 이벤트를 표현한 테스트 입력값입니다.

다만 이 파일이 스스로 실행되는 것은 아닙니다.

---

## ② curl 또는 Swagger가 HTTP 요청 전송

```
curl -X POST \
  http://127.0.0.1:8001/api/collect/order \
  -H "Content-Type: application/json" \
  -d @sample_events/order_created.sample.json
```

흐름:

```
Sample JSON 읽기
→ HTTP Request Body에 담기
→ POST /api/collect/order 전송
```

그림에는 이 단계가 빠져 있으므로 추가하는 것이 좋습니다.

## ③ `collector/routes/collect.py`가 요청 수신

다음 함수가 실행됩니다.

```
def collect_order_event(
    raw_body: dict[str, Any]
):
```

FastAPI가 요청 JSON을 Python 딕셔너리로 바꾸어 `raw_body`에 전달합니다.

```
HTTP JSON
→ raw_body 딕셔너리
```

## ④ `collector/schemas/events.py`의 계약으로 검증

`collect.py`가 다음 코드를 실행합니다.

```
event = OrderCreatedEvent.model_validate(
    raw_body
)
```

연결되는 파일:

```
collector/routes/collect.py
↓
collector/schemas/events.py
```

검증 대상:

```
OrderCreatedEvent
├── event_id
├── event_type
├── schema_version
├── source_system
├── event_time
└── payload: OrderPayload
```

정상 데이터이므로 검증을 통과하고 다음 객체가 만들어집니다.

```
OrderCreatedEvent 객체
```

그 후 다시 `collect.py`로 돌아옵니다.

## ⑤ `collector/services/ingest.py` 호출

검증에 성공했으므로 다음 줄이 실행됩니다.

```
saved_path = ingest_order_event(event)
```

연결 흐름:

```
collector/routes/collect.py
↓
collector/services/ingest.py
```

그림에서 `7`로 표시한 이 연결 자체는 맞지만, 실제 순서상 앞 단계와 이어지도록 **5번 정도로 변경**하는 것이 좋습니다.

## ⑦ 저장 경로 참조

`ingest.py`는 이미 import된 경로 변수를 사용합니다.

```
RAW_ORDER_FILE
```

경로:

```
data_lake/raw/order_events/order_events.jsonl
```

정확한 관계:

```
ingest.py
- - - → config.py의 RAW_ORDER_FILE 참조
```

여기서는 `config.py`가 다시 실행되거나 어떤 함수를 호출하는 것은 아닙니다.

## ⑨ Raw JSONL 파일에 한 줄 추가

`append_jsonl()` 내부 처리:

```
저장 폴더 확인
↓
폴더가 없으면 생성
↓
파일을 "a" 모드로 열기
↓
dict를 JSON 문자열로 변환
↓
끝에 줄바꿈 추가
↓
Raw JSONL에 한 줄 저장
```

저장 위치:

```
data_lake/raw/order_events/order_events.jsonl
```

이 부분은 현재 그림에 잘 표현되어 있습니다.

## ⑩ 저장 결과가 역순으로 돌아감

저장이 끝나면 다음 순서로 돌아갑니다.

```
append_jsonl()
↓ None 반환

ingest_order_event()
↓ Raw 파일 경로 반환

collect_order_event()
↓ 성공 응답 딕셔너리 생성
```

`ingest.py`:

```
return str(RAW_ORDER_FILE)
```

`collect.py`:

```
saved_path = ingest_order_event(event)
```

## ⑪ 사용자에게 `201 Created` 응답

`collect.py`가 다음 딕셔너리를 반환합니다.

```
return {
    "message": "주문 이벤트 저장 성공",
    "event_id": event.event_id,
    "order_id": event.payload.order_id,
    "saved_path": saved_path
}
```

그리고 데코레이터에서 설정한 상태 코드가 적용됩니다.

```
@router.post(
    "/order",
    status_code=status.HTTP_201_CREATED
)
```

최종 흐름:

```
collector/routes/collect.py
↓
FastAPI / Uvicorn
↓
curl 또는 Swagger
↓
201 Created 응답
```
