```
1. python -m collector 실행
        ↓
2. collector/__main__.py 실행
        ↓
3. uvicorn.run("collector.main:app") 호출
        ↓
4. Uvicorn이 collector/main.py import
        ↓
5. main.py의 import 문 실행
        ↓
6. collector/routes/collect.py import
        ↓
7. collector/schemas/events.py import
   → OrderPayload 클래스 정의
   → OrderCreatedEvent 클래스 정의
        ↓
8. collector/services/ingest.py import
        ↓
9. collector/core/config.py import
   → Raw, Dead Letter, Staging 경로 계산
        ↓
10. collector/core/lakehouse.py import
    → append_jsonl() 함수 정의
        ↓
11. ingest.py로 돌아와
    → ingest_order_event() 함수 정의
    → save_order_dead_letter() 함수 정의
        ↓
12. collect.py로 돌아와
    → router = APIRouter() 생성
    → @router.post("/order") 등록
    → collect_order_event() 함수 정의
        ↓
13. main.py로 돌아와
    → collect_router 별칭에 router 객체 연결
    → app = FastAPI() 생성
    → app.include_router(collect_router) 실행
    → @app.get("/health") 등록
        ↓
14. Uvicorn 서버 요청 대기
```
