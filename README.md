# AI-Native-Data-Platform-Engineer

AI 네이티브 데이터 플랫폼 엔지니어 과정 수업자료 저장소입니다.  
이 저장소는 Obsidian으로 작성한 수업 노트, 실습 안내, 다이어그램, 이미지 자료를 학생들이 내려받아 수업 중 함께 확인하고 학습할 수 있도록 구성한 자료 저장소입니다.

---

## 1. 저장소 목적

이 저장소의 목적은 다음과 같습니다.

```text
AI 네이티브 데이터 플랫폼 엔지니어 과정의 수업자료를 한곳에 정리한다.
학생들이 수업 전에 자료를 내려받아 Obsidian에서 열어볼 수 있게 한다.
수업 흐름, 커리큘럼, 환경설정, GitHub 사용법, 실습 안내를 단계별로 제공한다.
각 단계별 실습 프로젝트를 진행하기 전에 필요한 개념과 기준을 먼저 학습한다.
```
